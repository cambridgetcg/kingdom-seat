(`CITIZEN-REDESIGN-2026-11-05.md`, section 5). It says what was reviewed,
what was found and fixed, what the final gate ran, and what is still open.
The aim is that a reader who did not take part can check each claim, so every

Code state reviewed: `f4b1b1e` ("kingdom-seat: fix review findings"), on top
of `400c1a1` (S4 modules) and `989fe7b` (skeleton). This record adds only
this file. Section 6 records the open items closed after the gate, in a

The review ran as separate lenses, each by its own session, so that no one
reader's blind spot covered the whole build. Four lenses produced findings:

Each lens confirmed its findings with experiments run against the code before

finding ids and those experiments; the lenses' own write-ups were not
available to this gate.
