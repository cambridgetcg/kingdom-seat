(`CITIZEN-REDESIGN-2026-11-05.md`, section 5). It says what was reviewed,
what was found and fixed, what the final gate ran, and what is still open.
The aim is that a reader who did not take part can check each claim, so every

reader's blind spot covered the whole build. Four lenses produced findings:

finding ids and those experiments; the lenses' own write-ups were not

    server settles every handler when it stops
    (`test/helpers/fake-server.ts`), pinned by `test/helpers.test.ts`

    answers while it was still awaiting", which fails 3 of 3 with the old
    fake server.
